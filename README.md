# 流光媒体工作台

流光媒体工作台是一个 Windows 优先的 PySide6 桌面视频工具，包含“下载工作台”和“剪辑工作台”两个功能板块。下载模块会把播放页直接交给 `yt-dlp` 解析，并支持标准 HLS (`m3u8`)、DASH (`mpd`) 和普通媒体直链；剪辑模块使用本地 FFmpeg 完成非破坏性分镜、重排、音轨混合和导出。

主窗口默认以 1240×860 打开，支持最大化和拖动调整大小。下载队列、日志、剪辑时间线和视频预览会按窗口可用空间自动伸缩；视频画面保持播放器的宽高比，不会因放大窗口而拉伸变形。

## 直接启动

双击：

```text
启动流光下载器.bat
```

首次启动会在项目目录创建 `.venv`，自动安装 PySide6、yt-dlp、媒体处理后备组件及本地 AI 推理运行时。安装完成后会直接打开应用；以后启动不会重复安装。

也可以在 PowerShell 中运行：

```powershell
.\启动流光下载器.ps1
```

只检查运行环境而不打开窗口：

```powershell
.\启动流光下载器.ps1 -CheckOnly
```

验证当前源码环境或打包成品内的离线 AI 运行时：

```powershell
.\.venv\Scripts\python.exe .\main.py --check-ai-runtimes
.\dist\流光下载器\流光下载器.exe --check-ai-runtimes
```

## 使用步骤

1. 在地址框中每行粘贴一个完整的视频播放页地址。
2. 点击“批量分析”，在下载队列中查看每项的成功或失败结果。
3. 选择画质和保存目录。
4. 点击某一行的“下载”，或点击右上角“批量下载”下载全部分析成功项目。

需要登录的网站，可以在“浏览器登录状态”中选择已登录该网站的 Chrome、Edge 或 Firefox。浏览器 Cookie 由 yt-dlp 在本机读取，应用不会主动显示或保存 Cookie 内容。

## 剪辑工作台

点击窗口顶部“剪辑工作台”进入第二个功能板块：

1. 点击“导入镜头”，批量选择本地视频；长视频会先作为一个完整可编辑镜头进入视频轨。
2. 鼠标移入预览画面后，底部显示播放/暂停、进度拖动、倍速、音量/静音和全屏控制；移出后自动隐藏，不占用预览高度。
3. 选中视频轨镜头后可执行“智能分镜”，也可使用“播放头切分、复制、拖动重排、前移、后移、删除镜头”继续人工调整。
4. 在镜头属性中为相邻镜头选择直接切换、淡入淡出或交叉溶解，并调整转场时长。
5. 点击“识别字幕”使用已校验的 Whisper 模型生成逐句字幕；字幕会进入字幕轨，并可逐条修改时间、文字、启用状态或删除。
6. 点击“添加音轨”导入背景音乐或配音，在“音轨”属性页修改时间线开始位置、素材入点/出点、音量和停用状态。
7. 点击“自动精华”设置目标时长、镜头长度、场景灵敏度和本地模型增强；结果直接覆盖或追加到同一条可编辑视频轨。
8. 点击“智能解说”选择解说风格和草稿长度；Qwen2.5 3B 会通过本地 llama.cpp CPU 运行时依据字幕、镜头和选择依据生成草稿。草稿必须先经过人工修改/确认，再由 Windows 本机语音引擎离线生成 WAV 并加入音频轨，之后仍可调整开始时间和音量。模型不可用或推理失败时会明确回退到确定性规则草稿。
9. 在“项目”属性页设置横屏、竖屏、方形画布及帧率；保存为 `.slproj` 后可继续编辑。
10. 点击“导出成片”，FFmpeg 会在后台规范化镜头、执行转场、混合音轨并写入可开关的字幕软轨。

剪辑工作台支持撤销/重做。自动剪辑功能也将输出同一种可编辑项目结构，因此自动生成后仍可继续切分、删改、重排和重新导出。

窗口拉高或最大化时，新增的垂直空间优先分配给视频预览；多轨时间线保持稳定高度，超出时在轨道内部横向或纵向滚动。

### 长视频自动精华

导入一个或多个视频后点击“自动精华”：

- 可针对当前素材，或对素材库中的全部视频生成合并精华。
- 可设置目标总时长、单镜头最长时长和场景灵敏度。
- FFmpeg 会在本地缩小分析画面、检测场景切换，并按时间覆盖编排镜头；固定机位素材会自动采用均匀覆盖后备策略。
- 可选择替换当前分镜或追加到现有分镜；替换操作可以撤销。
- 生成结果会记录 `long_video_highlight` 配方参数，并继续支持人工入出点、切分、重排、删除、音量、音轨和导出调整。

不启用智能增强时，自动精华只使用确定性的场景和时间覆盖配方。启用已安装的本地模型后，语音、人脸/人物、画质、中文语义和画面多样性证据会实际参与候选镜头评分；任一可选分析器失败时会明确记录回退信息并继续使用确定性方案。

### 本地模型管理

点击窗口顶部“本地模型 x/7”，或在“自动精华/智能解说”对话框中点击“管理模型”：

- 管理界面会检查缺失、未完成、待校验、文件大小异常和已安装状态。
- 可直接从模型来源的 HTTPS 地址下载；界面实时显示已完成字节、总大小、速度和剩余时间。大文件写入 `.part`，取消会主动中断当前连接，再次点击“继续”会断点续传。GitHub 运行时资产优先使用系统 `curl` 备用通道，TLS 不稳定时仍保留 `.part` 进度，并支持及时取消。
- TLS EOF、读取超时、连接重置、提前结束和可恢复 HTTP 状态会按 1/2/4/8 秒自动重试并继续 `.part`；证书校验失败、404 等永久错误不会反复请求。
- 下载完成后执行 SHA-256 校验并记录版本、文件大小和摘要；也可以手动重新校验或删除本地文件。
- 模型保存在当前 Windows 用户的本地应用数据目录，不写入只读安装目录，升级应用不会删除模型。
- 缺失或未校验的模型会禁用对应开关，并显示准确的缺失数量。

当前模型包：

| 能力 | 模型 | 用途 |
| --- | --- | --- |
| 语音 | Whisper Small | 中文/多语言逐句时间戳和字幕证据 |
| 人脸/人物 | YuNet + MediaPipe Person | 人脸数量/占比、人物置信度和人物优先评分 |
| 语义编排 | BGE Small 中文 + CLIP | 对白语义新颖度、画面多样性和候选镜头评分 |
| 智能解说 | Qwen2.5 3B Q4 + llama.cpp Windows CPU 运行时 | 依据项目字幕和镜头事实生成可人工修改的中文解说草稿；不调用云端，也不要求安装 Python `llama_cpp` |

模型只在首次安装时需要网络。安装并校验完成后，识别、分析、剪辑、保存和导出均不访问云端。自动生成的镜头仍可修改入出点、切分、复制、重排、删除、调音或撤销；镜头的选择分数、选择依据和关联证据会保存在 `.slproj` 中。

如果连续自动重试后仍提示 `UNEXPECTED_EOF_WHILE_READING`，通常是本机 HTTPS 代理或所选代理节点在 TLS 握手/传输阶段断开连接。程序会在错误提示中显示检测到的代理主机与端口（不会显示代理账号密码）；请切换代理节点、重启代理程序或恢复可用网络后再次点击下载，已保存的 `.part` 会继续使用。

#### “校验”按钮做了什么

1. 校验任务在独立后台线程中运行，不会加载或执行模型，也不会上传文件。
2. 程序先检查每个文件的预期大小，然后每次读取 1 MB 计算 SHA-256；界面会显示校验进度、读取速度和剩余时间。
3. 对于注册表中带官方 SHA-256 的大模型文件，计算结果必须与官方摘要一致；其他辅助配置文件会在大小检查后记录当前摘要。
4. 摘要不一致时，原文件会被改名为 `.corrupt`，模型状态变为“文件异常”，可点击“修复”重新下载。
5. 点击取消后，校验会在当前 1 MB 分块结束时停止；不会删除已下载的模型文件，可随时重新校验。

## 功能

- 播放页、m3u8、mpd、媒体直链多行批量输入
- 顺序批量分析与逐项成功/失败反馈
- 单项下载与仅处理分析成功项目的批量下载
- 最佳画质、4K/2K/1080p/720p/480p 和 MP3 音频预设
- 浏览器登录 Cookie、Referer、User-Agent 高级选项
- 人工字幕和自动字幕选项
- 实时进度、速度、剩余时间和媒体处理状态
- 取消当前任务
- 自动断点续传、分片重试、重复下载记录
- 设置持久化和敏感查询参数日志隐藏
- 系统 FFmpeg、项目 FFmpeg、`imageio-ffmpeg` 后备三级探测
- 下载/剪辑双工作台切换
- 本地视频、音频批量导入和离线媒体探测
- 非破坏性分镜、精确入出点、播放头切分、复制、重排和删除
- 源视频预览、逐镜头音量和静音
- 导入完成后自动选中新素材；点击“预览”即可直接播放，加载和解码失败会在底部显示原因
- 视频内悬浮播放器控制层：鼠标移入或键盘聚焦时显示，移出后隐藏，支持播放/暂停、进度拖动、0.5×–2.0× 倍速、音量/静音和全屏
- 窗口增高时预览优先扩展，分镜时间线使用内部纵向滚动
- 视频、音频、字幕三类可视轨道、时间标尺、播放头和时间线缩放
- 镜头拖动重排、播放头切分、智能分镜、删除/插入，以及切换、淡入淡出和交叉溶解转场
- 多条附加音轨的开始时间、裁切、音量和停用设置
- Whisper 一键识别字幕、字幕轨逐条编辑和 MP4 字幕软轨导出
- 参数化自动精华和离线智能解说；生成的镜头、字幕、解说音轨继续支持人工修改
- 本地 Qwen2.5 + llama.cpp 事实型解说草稿、生成中取消、失败规则回退、人工改稿和 Windows SAPI 配音
- 横屏、竖屏、方形输出画布与帧率设置
- `.slproj` 项目保存/打开、撤销/重做和可编辑 `EditPlan`
- 可取消的后台 FFmpeg 规范化、合并、混音和 MP4 导出
- 可取消的离线场景检测和目标时长长视频精华配方
- 单素材或全部视频素材的合并精华生成，结果可撤销并继续人工修改
- 本地模型缺失/损坏检查、管理界面直接下载、取消、`.part` 续传、校验和删除
- Whisper 离线逐句时间戳、字幕证据与项目持久化
- YuNet 人脸、MediaPipe 人物、清晰度/曝光/对比度离线评分
- BGE 中文语义与 CLIP 画面多样性评分，真实参与精华候选选择
- 镜头选择依据、评分与证据关联展示，自动结果继续支持完整人工修改

## 运行环境

- Windows 10/11
- Python 3.11 或 3.12
- 可以访问 PyPI 的网络（仅首次初始化需要）

应用优先使用系统 FFmpeg。系统未安装 FFmpeg 时，会使用 `imageio-ffmpeg` 随依赖提供的后备可执行文件。剪辑工作台会优先使用 FFprobe 读取媒体信息；没有 FFprobe 时自动回退到 FFmpeg 探测。某些特殊格式仍可能要求完整版 FFmpeg/FFprobe，此时可通过 `winget install Gyan.FFmpeg` 安装并重启应用。

本地素材的分析、剪辑、项目保存和导出均可完全离线运行。下载网络视频时仍然需要网络连接。

本地模型也需要在首次安装时联网下载。之后即使断网，已校验模型仍可运行；没有安装模型时，普通人工剪辑和确定性场景精华不受影响。

## 打包 EXE

先至少成功启动一次应用，再执行：

```powershell
.\build.ps1
```

输出目录：

```text
dist\流光下载器\流光下载器.exe
```

默认使用 `onedir`，比单文件模式启动更快，也更适合 yt-dlp 的大量站点解析模块。分发时应复制整个 `dist\流光下载器` 文件夹。

## 更新 yt-dlp

网站经常改变播放器接口。遇到原先支持的网站突然无法解析时，可以更新本地环境：

```powershell
.\.venv\Scripts\python.exe -m pip install -U "yt-dlp[default]"
```

## 支持范围

“通用”表示支持 yt-dlp 已适配的网站，以及没有 DRM 的标准 HLS/DASH/媒体直链。它不保证支持所有网站，也不会绕过：

- Widevine、FairPlay、PlayReady 等 DRM
- 付费墙、验证码或网站访问控制
- 已失效的签名链接
- 用户没有权保存的内容

请仅下载你拥有或已获授权保存的媒体，并遵守相关网站条款和版权规定。
